# MovieLog

영화 리뷰를 작성하고 관리하는 PHP 기반 CRUD 웹앱입니다. 로그인/회원가입, DB 연동, 폼 처리 등 웹 백엔드 기초를 연습하기 위한 프로젝트입니다.

## 기능

- 회원가입 / 로그인 / 로그아웃 (`login.php`, `signup.php`, `logout.php`)
- 프로필 조회 및 수정 (`mypage.php`, `edit_profile.php`)
- 영화 리뷰 작성 및 상세 조회 (`movie_write.php`, `request_movie_detail.php`)

## 기술 스택

- PHP (세션 기반 로그인)
- MySQL

> 웹 백엔드 기초를 다지기 위한 초기 연습 프로젝트로, 스타일링·유효성 검사 등은 포함되어 있지 않습니다.
